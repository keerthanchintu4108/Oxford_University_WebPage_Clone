# 🎓 University Website

## 📌 Project Overview

This project is a **University Website** developed using **HTML and CSS**.
It presents university information such as courses, campus locations, facilities, and student testimonials in a structured and visually appealing layout.

The project demonstrates **basic front-end web development skills**, including page layout design, navigation menus, responsive sections, and styling using CSS.

---

## ✨ Features

* Responsive website layout
* Navigation bar with menu links
* Hero banner section
* Courses offered section
* Global campus locations
* University facilities display
* Student testimonials section
* Footer with university details

---

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* **Google Fonts**
